词库管理 · 新词导入、修改与删除

先生成提示语 → 复制给大模型 → 粘贴生成的 JSON → 选择年级并确认。任一字段为空或格式不符，整批导入失败，不会添加部分词语。同年级、同模式已有的词语会自动覆盖更新；同一批数据里同模式的重复词条仍会提示错误。

当前为班级云端词库。只有本班老师可以修改；保存后学生在进入班级、点击同步或开始练习前获取新版，不需要更新 GitHub 文件。

默认同时加入两个模式，也可仅加入其中一个。首页词数和选词列表随练习模式切换。导出的 JSON 会保留模式信息；导入这类 JSON 时，按其模式与上方所选模式的交集添加。

④ 修改或删除已有词条

先在第③步选择年级和模式，再选择词条。选择两个模式时，修改或删除会同时影响两个模式；其他年级不变。可以在 JSON 中修改词语、拼音、英文释义及逐字资料，格式校验规则与导入相同。

清空范围以第③步选择的年级和模式为准，包含该范围内所有词条，不受搜索框筛选影响。操作前会再次确认；清空不会删除学生账号或历史学习记录。

班级词库保存在云端。老师的修改仅影响本班，保存成功后学生同步即可获取；备份 JSON 仅用于下载留存。
